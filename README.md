# BEAR MODE Telegram bot

## Что умеет
- Показывает 4 сета по 170 000 ₫.
- Собирает количество, имя, телефон, адрес и комментарий.
- Просит клиента подтвердить заказ.
- Отправляет подтверждённый заказ владельцу в личные сообщения Telegram.

## Важно
Не публикуйте BOT_TOKEN и не отправляйте его посторонним. Если токен случайно раскрыли, перевыпустите его через @BotFather командой `/revoke`.

## Настройка
1. Установите Python 3.10 или новее.
2. Установите зависимости:
   `pip install -r requirements.txt`
3. Задайте переменные окружения:
   - `BOT_TOKEN` — токен от @BotFather.
   - `ADMIN_CHAT_ID` — ваш числовой Telegram chat ID (узнать командой `/myid`).
   - `WEB_APP_URL` — адрес опубликованного сайта; по умолчанию `https://luckykurbaniss.github.io/bear-mode-bot/`.
4. Запустите:
   `python bot.py`

## Как узнать ADMIN_CHAT_ID
1. Запустите бота.
2. Откройте своего бота в Telegram и нажмите Start.
3. Отправьте ему команду `/myid`.
4. Скопируйте число из ответа и задайте его как `ADMIN_CHAT_ID`.
5. Перезапустите бота.

Telegram не позволяет боту первым написать человеку только по @username. Поэтому владелец должен сначала открыть бота и нажать Start, а для доставки уведомлений нужен числовой chat ID.

## Размещение и заказы с сайта

Сайт размещается отдельно на GitHub Pages. Сам GitHub Pages не запускает Python-бота: бот должен постоянно работать на Python-хостинге/worker-сервисе в режиме long polling.

Для запуска сервиса:
1. Подключите репозиторий `luckykurbaniss/bear-mode-bot` к Python-хостингу, который поддерживает постоянные фоновые процессы.
2. Команда запуска: `python bot.py`.
3. Добавьте переменные окружения `BOT_TOKEN` и `ADMIN_CHAT_ID`. При необходимости задайте `WEB_APP_URL` (адрес сайта).
4. Убедитесь, что сервис работает постоянно и в логах есть `BEAR MODE bot is running!`.

В Telegram нажмите Start у своего бота. Команда `/myid` покажет числовой ID владельца. После настройки `ADMIN_CHAT_ID` магазин открывается через постоянную кнопку «Магазин» внизу чата или через клавиатурную кнопку «Открыть меню и заказать». Для клавиатурного запуска сайт передаёт заказ через Telegram `sendData`; для запуска через нижнюю кнопку меню используется защищённый HTTPS API `/api/order` на HOKAS с проверкой подписи `initData`. В обоих случаях бот сохраняет заказ и отправляет его владельцу в личные сообщения.

Не загружайте файл с токеном в репозиторий и не публикуйте токен.

## Изменение ассортимента
Состав сетов и цену можно изменить в начале `bot.py` в словаре `SETS` и переменной `PRICE`.
