# BEAR MODE Telegram bot

## Что умеет
- Показывает 4 сета по 170 000 ₫.
- Собирает количество, имя, телефон, адрес и комментарий.
- Просит клиента подтвердить заказ.
- Отправляет подтверждённый заказ владельцу в личные сообщения Telegram.

## Важно
Не публикуйте BOT_TOKEN и не отправляйте его посторонним. Если токен случайно раскрыли, перевыпустите его через @BotFather командой `/revoke`.

## Настройка
1. Установите Python 3.10 или новее.
2. Установите зависимости:
   `pip install -r requirements.txt`
3. Задайте переменные окружения:
   - `BOT_TOKEN` — токен от @BotFather.
   - `ADMIN_CHAT_ID` — ваш числовой Telegram chat ID.
4. Запустите:
   `python bot.py`

## Как узнать ADMIN_CHAT_ID
1. Запустите бота.
2. Откройте своего бота в Telegram и нажмите Start.
3. Отправьте ему команду `/myid`.
4. Скопируйте число из ответа и задайте его как `ADMIN_CHAT_ID`.
5. Перезапустите бота.

Telegram не позволяет боту первым написать человеку только по @username. Поэтому владелец должен сначала открыть бота и нажать Start, а для доставки уведомлений нужен числовой chat ID.

## Размещение
Бот работает в режиме long polling. Его можно разместить на постоянно работающем Python-сервисе/worker-хостинге. Добавьте `BOT_TOKEN` и `ADMIN_CHAT_ID` в Environment Variables сервиса. Не загружайте файл с токеном в публичный репозиторий.

## Изменение ассортимента
Состав сетов и цену можно изменить в начале `bot.py` в словаре `SETS` и переменной `PRICE`.
